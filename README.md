# NighThematic

## A night-themed web app for generating night themed AI images using Hack Club AI

### Features:
1. Generates images only in dark-themed
2. Realistic Images using Gemini 2.5 Flash Image
3. Less wait time of about 10-15 seconds.

### How to test it?

1. Go over to: ![NighThematic](https://nighthematica.vercel.app/)
2. Test it :)

### How to run it locally?

1. Clone the repository.
2. Create a .env file in the project root and add your `HACKCLUB_API_KEY`
3. Run `npm install`
4. Login to vercel using `vercel login` and then run using `vercel dev`.
